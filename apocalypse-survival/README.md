# 末日求生 · 青阳市

文字末日生存 RPG（网页版）。后启示录的中国青阳市，丧尸横行、幸存者稀少、人性复杂，没有血清也没有救援——唯一的结局是死亡。

> 原始设定来自一份给 LLM 当游戏主持人（GM）的规则书。本项目把它做成可玩的网页：
> **数值、骰子、行动力、衰减全部由本地引擎确定性裁定**（玩家手输加属性无效，正如设定要求），
> **AI 只负责把每回合的结果写成冷冽粗粝的叙事并给出选项**。
> 没有 API key 也能玩 —— 内置离线模板叙事。

> **关于**：项目由 **Aria** 提出，原始游戏设定亦出自 Aria。游戏的**整体方向**（世界观、机制框架、玩法走向）以 Aria 的设计意图为准；其余为协助实现与托管。涉及大方向的改动，请先与 Aria 确认，不要擅自定调。

## 直接玩

双击 `index.html` 用浏览器打开即可（无需服务器、无需安装）。

建议用本地静态服务器以获得最佳字体/网络行为：

```bash
cd 末日求生
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 接入 AI 叙事（可选）

点右下角 ⚙ 或建角页「叙事 AI 设置」：

- **离线模板**（默认）：无需 key，开箱即玩，叙事较简。
- **Claude**：填 `api.anthropic.com` 的 key，模型如 `claude-sonnet-4-6`。
- **OpenAI 兼容 / DeepSeek**：填 key + Base URL（如 `https://api.deepseek.com`），模型如 `deepseek-chat`。

> Key 只存在本机 `localStorage`，不上传。浏览器直连第三方 API 需对方允许 CORS（Anthropic 已支持浏览器直连；DeepSeek 等视其策略）。

## 游戏机制（已实现）

- **四条生存数值**：生命 / 饱腹 / San / 感染。分级会施加判定修正（如重伤战斗 -15%、饥饿智力 -10%、感染压低生命上限）。归零/满值即对应死亡。
- **七项骰值属性**：力量 / 敏捷 / 智力 / 感知 / 口才 / 幸运 / 魅力。d100 vs 有效属性，分大成功 / 成功 / 失败 / 大失败（每次结果可展开「判定详情」查看掷骰）。
- **以「周」为回合**：每周 4 点行动力，11 种行动各耗 1 点；用尽后周末结算（随机事件 + 进入下一周）。
- **行动**：寻找物资 / 修缮庇护所 / 训练属性 / 制造改装 / 清理丧尸 / 交流招募 / 深度休整 / 研究阅读 / 队友闲聊 / 祈祷冥想 / 自主发挥。
- **自然语言行动输入**：输入框会优先把“去医院找药 / 清理超市丧尸 / 训练力量”等句子路由到正式行动；无法路由的描述会进入自主行动意图判定，由引擎按侦察、破障、修理、交涉、潜行、觅食等类型摇骰结算。
- **物品使用（不耗行动力）**：在状态面板点食物→回饱腹、医疗物品→回生命、消毒剂/抗生素→压制或降感染（消毒剂仅在感染<61 时有效，抗抑郁药多次用有副作用）。数值范围严格对齐原设定。
- **携带 / 仓库分栏**：背包有容量上限（带背包 12 / 无 6），溢出自动暂存据点仓库，可在面板里「存 / 取」。
- **地图路线系统**：外出不再只是选地点。青阳市有从庇护所通往各地点的路线网络；每条路线都有额外风险、噪音、路障和隐藏状态。搜刮、清理、侦察和周末事件会让路线变吵、堵塞、安静或暴露捷径。
- **区域态势 / 动态威胁**：居民区、超市、药店等地点拥有独立威胁等级与遭遇风险；搜刮、清理丧尸和周末事件都会让具体区域恶化或缓和，状态面板会显示风险情报。
- **职业**：影响初始属性、初始物品与定位（如军人可用步枪、医生医疗强、明星魅力高）。
- **NPC / 队友**：好感度 -100~100，可招募 ≤5 名；NPC 会带有势力背景、性格、恐惧、压力、伤势和忠诚倾向。危险行动会让队友压力上升或受伤，闲聊/休整可以稳定队友；**队友会在凶险行动与坏事件中死亡**（死亡率与普通 NPC 相同），目睹会重创 San 与其他队友压力。
- **幸存者势力**：南桥营地、黑市车队、铁锈帮、白塔医援、旧警戒线都有独立声望、活动区域和态度档位。地点接触、招募成败、周末事件会改变势力关系，状态面板会显示当前声望。
- **主线谜团 / 事件链**：围绕“零号档案”逐步收集线索。搜刮、研究、自主侦察和周末事件都有机会发现地点相关线索；线索数量会推进主线阶段，状态面板会显示当前阶段、进度和最近线索。
- **周末随机事件**：好坏各半（暴雨 / 尸群迁徙 / 地震 / 贸易车队 / 遗留日记 …）。

## 体验

- **选项可点**：叙事下方的编号选项是按钮，点一下即触发对应行动（也仍可在底部菜单选，或直接打字做自由行动）。
- **离线涌现叙事**：无 API key 时，叙事不再是机械复述——按地点 / 伤情 / 感染 / 队友 / 周数从片段库程序化拼装，每次都不同，并生成贴合处境的选项。
- **自动存档**：每个回合自动存本地；重开页面可「继续上一局」。
- **存档导出 / 导入**：建角页和游戏内状态面板都可导出 JSON 备份；导入时会校验格式并覆盖当前自动存档。
- **移动端**：窄屏顶栏有「状态」按钮可呼出/收起面板。

## 文件结构

```
index.html        入口
css/style.css     视觉 + 叙事游戏式可点交互
js/data.js        静态内容与规则表（职业/物品效果/地点/事件/修正表/系统提示词）
js/engine.js      确定性引擎（状态/骰子/行动/物品使用/携带仓库/队友死亡/衰减/死亡判定/存档）
js/offline.js     离线涌现叙事器（按处境程序化拼装的片段库）
js/narrator.js    叙事路由（Claude / OpenAI 兼容 / 离线）
js/ui.js          界面控制器（可点选项/面板交互/存档）
```

## 设计取舍

把「算账」和「讲故事」分开：引擎保证数字永远正确、不可作弊（满足设定里「后台摇骰」的要求），AI 负责沉浸感。这样即便不接 AI，核心循环也完整可玩；接上 AI 后，叙事、NPC 言行与突发剧情会丰富得多。
