# 多人 / 2-4 人联机 · 设计 brief

> 状态：**待 Aria 拍板**。这是世界观/玩法走向的大方向改动，按 README 规矩先与 Aria 确认再动工。
> 本文是讨论沉淀 + 分期路线图，给 Aria 看、当讨论底稿。

## 一句话

把这个单机文字末世 RPG 做成 **2-4 个朋友一起玩**——但不是「一起苟」，而是**剧本杀式的分工 + 共担 + 偶尔背叛**。

## 为什么这游戏天生适合

它的架构本来就是「**引擎当公正裁判**（数值/骰子不可作弊）+ **AI 当 GM**（只负责讲故事）」——这正是剧本杀的骨架：一个公正裁判管规则，一个 GM 推剧情。它最早还是从「给 LLM 当 GM 的规则书」来的，所以往多人走是顺血统的，不是硬掰。

## 三种「联机」形态，别混为一谈

| | 形态 | 好玩程度 | 说明 |
|---|---|---|---|
| **A** | 合作生存（一起苟） | ✕ 最低 | N 个人并排各管各的血条，不会更好玩，还引入「按回合互相等」的硬伤。**别做这个。** |
| **B** | 剧本杀式（隐藏身份 / 秘密目标 / 背叛 / 势力牵连） | ◎ 最高 | 乐趣来自人和人之间：谁可信、谁被感染瞒着、资源不够谁先动手。正好接 README 路线图里的「背叛/势力牵连」。 |
| **C** | 异步 play-by-post | ○ 折中 | 世界共享、各人按自己时间走、AI 织成连续叙事。绕开「实时等回合」，最像论坛跑团。 |

**方向：奔 B（或先用异步 C 落地），不做 A。**

## 为什么 2-4 人是甜区

小群正好化解了 A/B 最大的硬伤——「按周回合互相干等」：
- 要么 **同时规划**：大家各自把这周 4 点行动力规划好，引擎一起结算。
- 要么 **异步**：谁有空谁先走，AI 把进度织成连续叙事。

都行，而且 **不需要重型实时后端**。

## 架构代价（诚实）

会打破现在最值钱的性质——**纯静态 / 零后端 / 玩家自带 AI key / 双击即玩**。多人需要：
- **共享状态**（一份世界 + 各人角色）
- **回合协调**（同时结算 或 异步推进）
- **一条通道**（异步用普通存储即可；实时用 Supabase Realtime / PartyKit 这类）
- **AI 叙事费用** 从「各人自付」变成「得有人替整局付」。

## Project Zomboid：借什么、不借什么

**别借**：PZ 的魅力来自实时深度模拟——逐格走位、近战手感、背包 tetris、分钟级需求条。这些是「实时沙盒」这个媒介的东西，搬进文字回合制只会变成一张没有戏的 Excel。文字版战斗保持现在的抽象摇骰，别仿真空间微操。

**该借**（按性价比排）：
1. **特质 + 职业（traits & occupations）** — 最该抄。开局点选正负特质（体弱/嗜睡/勇敢、厨师/警察/医生……）。文字游戏几乎零实现成本，却一下给足重玩性；更关键的是**天生解决 2-4 人分工**——一个懂医的、一个修理工、一个会交涉的话痨、一个老兵，每人 build 不同、在队里不可替代。把「联机」从「一起苟」拉向「剧本杀式分工」的最便宜杠杆。
2. **情绪 / 恐慌系统** — 接 README 的「压力崩溃」。PZ 除了饿渴还有无聊、不爽、恐慌、抑郁。文字版加一条「精神/士气」，到阈值触发崩溃事件（乱跑、拒绝行动、对队友失控）——多人时这就是戏剧火药。
3. **世界按时钟恶化** — PZ 经典张力是「第 X 天水电断了，从此真末世」。现在只有每周代谢衰减；借这套升级节奏（某周电台失灵 / 据点水源枯 / 丧尸潮迁入），给回合制持续注入紧迫感，且是全队共担。
4. **干中学的技能成长**（替代/补充现在的「训练属性」）+ **感染的不确定性**（那一下抓伤到底有没有让我中招？PZ 的恐怖正来自这个悬念；已有「无血清缓慢上升」的底子，把「知不知道自己中招」做成隐藏信息，多人时杀伤力极大）。
5. **「这就是你的死法」** — PZ 的 slogan，本游戏「唯一结局是死亡」同调，死亡回顾/讣告已对齐。

PZ 的多人玩法本身也背书 B：**共享据点 + 分工 + 一损俱损（外加偶尔的背叛/猪队友把尸潮引回家）**，不是各苟各的。2-4 人正是这个的舒适区。

## 筛选铁律

回合制 + 文字扛不住 PZ 那么多系统。**每借一个系统都要问：它产出一个叙事抉择、或一次玩家互动了吗？** 只是「又多一根要填的条」就别加。Aria 这轮改的全是「饱腹别掉太快、吃喝别卡流程」——本质在跟「管血条的杂活」作斗争；无脑照搬 PZ 的一堆需求条只会放大这个问题。**标准一条：能制造人和人之间的戏，或一个真选择，才留。**

## 分期路线图

**Phase 0 — 特质/职业（纯单机，零联机依赖，现在就能做）**
- 开局点选职业 + 正负特质，影响属性/判定/起始物资。
- 立刻提升当前单机重玩性，**同时是 2-4 人角色分工的地基**。「为将来联机铺路，但现在就有收益」的安全切片。
- 可顺带加「精神/士气 → 崩溃事件」和几个「世界按时钟恶化」事件。

**Phase 1 — 异步 / 共享世界（play-by-post）**
- 一份共享世界 + 各人角色，谁有空谁推进，AI 织连续叙事。
- 技术最轻：一个共享存储（Supabase 之类）即可，不用实时通道。
- 先验证「多人 + 引擎裁判 + AI GM」的核心循环好不好玩。

**Phase 2 — 实时 2-4 人 co-op + 隐藏身份/背叛（完整 B）**
- 房间码 + 实时通道（Supabase Realtime / PartyKit）。
- 同时规划这周、引擎一起结算；每人一个隐藏目标/秘密，资源稀缺逼出信任与背叛。
- 复用已有的 hero+ally mascot（每个队友一个立绘 + 状态条 = 现成 co-op HUD）。
